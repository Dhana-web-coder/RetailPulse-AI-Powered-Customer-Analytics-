# RetailPulse
## AI-Powered Customer Analytics and Forecasting Platform

### Project Overview
RetailPulse is an AI-powered retail analytics platform developed to analyze customer behavior, forecast sales, predict customer churn, and optimize inventory management.

### Project Objectives
- Analyze retail sales performance.
- Understand customer purchasing behavior.
- Identify potential customer churn.
- Forecast future product demand.
- Improve inventory management.

### Key Features

#### 1. Sales Dashboard
- Total Sales
- Total Orders
- Unique Customers
- Total Quantity
- Daily Sales Trend
- Top 10 Countries by Sales

#### 2. Customer Analytics
- Customer Segmentation
- RFM Analysis
- New vs Returning Customers
- Monthly Active Customers
- Top Spending Customers

#### 3. Churn Prediction
- Customer Churn Analysis
- Churn Risk Identification
- Machine Learning Prediction

#### 4. Demand Forecasting
- Sales Forecasting
- Monthly Sales Analysis
- Forecast Model Evaluation

#### 5. Inventory Optimization
- Product Demand Analysis
- High and Low Demand Products
- Stock Risk Analysis
- Inventory Recommendations

### Technologies Used
- Python
- Pandas
- NumPy
- Scikit-learn
- Streamlit
- Machine Learning
- Matplotlib
- Plotly

### How to Run

1. Install required packages:

   pip install -r requirements.txt

2. Run the application:

   streamlit run app.py

Data Science and Analytics

### Conclusion
RetailPulse helps retailers make data-driven decisions through customer analytics, sales forecasting, and inventory optimization.
